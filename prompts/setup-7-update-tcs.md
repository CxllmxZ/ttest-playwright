Rules file for AI. User pastes a minimal invocation (see `doc/AGENT_PROMPTS.md`).

Setup 7 is **mechanical**. `data.ts` is regenerated by `scripts/setup-5.mjs --data-only`, not by you. Your job: run the script, then explain the result to the user in Thai.

Extract the 4 values exactly as written.

## When to use

The feature folder exists and one of these changed:
- `_scenarios/<feature>.csv` — rows added (Setup 4) or edited/deleted by hand
- `_locators/<feature>.ts` — locators added/removed/reordered by dev. **The CSV must be updated to the new locator count first**, otherwise the script stops.

Not for: new feature → Setup 5. New `|action` or locator type → Setup 6 first.

## Rules

1. **Check the script exists** at `scripts/setup-5.mjs`. If missing → **STOP**: "ไม่พบ scripts/setup-5.mjs — ต้องติดตั้งสคริปต์ก่อน". **Do NOT create or reconstruct it.**

2. **Run exactly this command** from the repo root (quote values with spaces):

   ```
   node scripts/setup-5.mjs <project> <access-flow> <module> <feature> --data-only
   ```

   Run once. No other flags. Do not retry with different values.

3. **Report** (below).

## Reporting

### Exit code 0 (✅)

In Thai: total TCs, which TC-IDs were added / removed (from script output), next step = the `npx playwright test ...` command printed.

If "หายไปจากเดิม" (removed) is not `-`, point it out — the user should confirm those TCs were meant to be deleted.

### Exit code 1 (❌)

Nothing was written. Show the error message as-is, then route:

| Message says | Go to |
|---|---|
| ยังไม่มีโฟลเดอร์ … → Setup 5 | Setup 5 |
| `…/_scenarios/<feature>.csv` … (item count, quotes, TC-ID, `�`) | Fix the listed rows in the CSV **in VS Code** (not Excel), then rerun Setup 7 |
| ไม่รู้จัก action … → Setup 6 | Setup 6, then rerun Setup 7 |
| `…/_locators/<feature>.ts` … | Setup 3 |
| `…helper.ts` ไม่มี action case | helper was edited incorrectly — report to dev |
| ไม่พบไฟล์ | Missing files listed: `_locators/` → Setup 3, `_scenarios/` → Setup 4, `helper.ts` → Setup 5 |
| ต้องระบุ 4 ค่า | Ask the user to complete the Location block |

Any other error → show it and stop. Do not guess a fix.

Keep the report short. Thai. Do not paste `data.ts`.

## Notes

- `helper.ts` imports `_locators/` at runtime, so locator changes take effect without regenerating helper — but every CSV row must still have exactly N items (N = new locator count). The script enforces this; the helper also throws at runtime if they differ.
- Allowed `|actions` are read from this feature's `helper.ts` switch, so actions added by Setup 6 are accepted.
- Changelog: 2026-09-28 (v10) — Setup 7 runs `setup-5.mjs --data-only` instead of AI regenerating `data.ts`. Removed "fewer items is OK" / "extra items discarded" rules (item count must equal N).
